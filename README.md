# Chill Vibes Music Player 🎧

A beautiful, dark-themed, glassmorphism music player built entirely with HTML, CSS, and vanilla JavaScript. Designed for late-night coding sessions and relaxing moments. 

## Features
- **Custom Audio Player**: Fully functional Play, Pause, Next, Previous, and progress seeking.
- **Library Filtering**: Search by song name/artist, or filter by vibe (Lo-Fi, Night Drive, etc.).
- **Favorites System**: Like songs and save them directly to your browser using `localStorage`.
- **Light/Dark Mode**: A smooth toggle that saves your preference.
- **Glassmorphism UI**: Beautiful blurs, gradients, and subtle glowing shadow effects.
- **Fully Responsive**: Adapts seamlessly to mobile, tablet, and desktop screens.
